# UWB CSV to VINS-Mono Bag

This folder contains example UWB CSV files for adding `/uwb/range` messages to bags generated by `tools/kalibr_bagcreater.py`.

## Generic Format

`generic` writes one UWB range message per row:

```csv
timestamp,anchor_id,range
465150.400000,0,3.0
465150.600000,0,4.0
```

The output message type is `vins_estimator/UWBRange`.

## Three Anchor Format

`three_anchor` writes up to three UWB range messages per row:

```csv
timestamp,D0,D1,D2
465150.400000,3.0,5.0,6.0
465150.600000,4.0,6.0,7.0
```

`D0`, `D1`, and `D2` become `anchor_id` 0, 1, and 2. Empty or invalid values are skipped.

## Create a Bag With UWB

Use timestamps in the same clock/time base as the image and IMU messages.

```bash
python3 tools/kalibr_bagcreater.py \
  --video xxx.mp4 \
  --imu imu.csv \
  --video_time_file frame_timestamps.txt \
  --output_bag output_with_uwb.bag \
  --uwb_csv tools/uwb/example_uwb_generic.csv \
  --uwb_format generic
```

For three-anchor CSV:

```bash
python3 tools/kalibr_bagcreater.py \
  --video xxx.mp4 \
  --imu imu.csv \
  --video_time_file frame_timestamps.txt \
  --output_bag output_with_uwb.bag \
  --uwb_csv tools/uwb/example_uwb_three_anchor.csv \
  --uwb_format three_anchor
```

Optional UWB arguments:

```bash
--uwb_topic /uwb/range
--uwb_frame_id uwb
--uwb_time_unit s
```

`--uwb_time_unit` supports `s`, `ms`, `us`, and `ns`. Decimal timestamps are interpreted as seconds by the existing time parser.

## Check the Bag

```bash
rosbag info output_with_uwb.bag
```

Expected topic entry:

```text
/uwb/range    vins_estimator/UWBRange
```

Check messages during playback:

```bash
rosbag play output_with_uwb.bag
rostopic echo /uwb/range
```

## Validate in VINS-Mono

Set `use_uwb: 1` in the active VINS-Mono YAML config, then run `vins_estimator` and play the bag. The estimator terminal should show:

```text
UWB received
UWB interpolated
Estimator UWB frame associated
```

At this stage UWB data is only loaded, aligned, and cached per frame. It is not added to backend optimization.
